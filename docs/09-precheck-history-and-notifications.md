# Pre-check history and notifications

## Pre-check week view (Director + Workshop only)
- One tap from Pre-checks tab. Rows = assets, columns = last 7 days.
- Cell: green (done, fine), yellow/red (done, flagged), grey (not done). Tap → pre-check report.
- Per asset: last pre-check date, by whom, days since last check.
- Filter by type, crew, yard; sort by days since last check.
- Assets with status Parked / not in use are excluded.

## Missed pre-check report
- Active assets with no pre-check for > 7 days.
- Auto-sent every Monday morning to Director + Workshop lead: asset, last check date, last checked by, crew.
- Alert on the day an asset passes 7 days.
- Run any time from week view; download PDF.

## Notifications
### Automatic (Director can toggle each and change recipients)
| Event | Recipients |
| --- | --- |
| Red pre-check item / Unusable breakdown | Workshop lead, crew Supervisor, Director |
| Yellow pre-check item / Still-usable breakdown | Workshop lead |
| WO assigned | Assigned mechanic |
| WO needs approval | Director |
| PO + job pack sent | Workshop lead (copy) |
| WO closed | Original reporter, Workshop lead |
| Service due soon / overdue | Workshop lead (+ Director if overdue) |
| Compliance expiring in 30 days | Office, Workshop lead |
| Asset > 7 days without pre-check | Workshop lead, Director |
| Weekly missed pre-check report | Director, Workshop lead |

### Director messages
- To one user, several, a crew, or a user type.
- Optional "must acknowledge" with read tracking.

### Channels
- In-app bell with unread count; each notification links to its record.
- Push for urgent items.
- SMS only for red flags / Unusable breakdowns.
- Email for weekly report and daily summaries.
All sends and acknowledgements logged.
