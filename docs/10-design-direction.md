# Design direction (to be expanded)

- Minimal: no unnecessary subtext, helper lines or minor headings.
- Three-colour palette used consistently (TBC); green / yellow / red reserved for asset and flag status.
- Assets shown as a scrolling strip of cards like products in a clothing app: photo, code + name, status colour; swipe / ticker-style auto-scroll.
- Calibri-style font (Carlito); flat, no gradients or shadows.
- Large glove-friendly tap targets on phone screens.

## Setup kept out of everyday use
- All configuration behind one **Setup** button (gear). Everyday screens show only the work — no add/configure/edit-template controls in daily flows.
- Setup holds: assets (add, edit, import, QR labels, service intervals, documents); asset types + pre-check templates; users (approve accounts, assign types, crews, flags, deactivate); crews and yards; suppliers; notification rules; company details, sign-up link, approval limit, Xero.
- Setup visibility: Director all; Workshop assets/templates/intervals; Office pending users, suppliers, compliance docs; Supervisor and Crew never.
- First-run guided setup for a new company: company details → yards and crews → assets → first pre-check templates → sign-up link. Then out of the way.
- Setup screen design TBC with the rest of the UI.
